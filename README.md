## English

### Overview
`image-to-pdf` is a lightweight, browser-based tool that converts images to PDF files entirely locally. All processing happens in your browser — your images are never uploaded to any server. It supports batch conversion, lossless quality, flexible page settings and both merged and single-file output modes.

### ✨ Key Features
- **100% Local & Offline** — All conversion runs directly in your browser. No server, no upload, no data leaves your device.
- **Lossless Image Quality** — Original JPG files are embedded losslessly. No compression, no quality loss.
- **Batch Conversion** — Add multiple images at once. Merge all images into one PDF, or generate a separate PDF for each image.
- **Flexible Page Layout** — A4 page size, auto orientation matching your image, and adjustable margins.
- **No Watermark & Free** — Completely free to use, no registration, no file limits, no hidden costs, no watermarks on output.
- **Cross-Platform** — Works on Windows, macOS, Linux, iPhone and Android. No installation required.

### 📸 Supported Image Formats
- JPG / JPEG
- PNG
- WebP
- TIFF / TIF
- HEIC
- BMP
- GIF

### ⚙️ Conversion Settings
| Setting | Options |
|---------|---------|
| Output mode | Merge into one PDF / Separate PDF per image |
| Page size | A4 (210 × 297 mm), auto-fit image |
| Orientation | Auto (matches image aspect ratio) |
| Margins | Normal (15 mm), customizable |
| Image quality | Lossless (keep original quality) |
| File name | Custom output file name |
